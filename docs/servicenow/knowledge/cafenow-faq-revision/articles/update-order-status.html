Recorded lifecycle

Submitted -> Confirmed -> Ready for Pickup -> Closed Complete. Canceled is a separate outcome. Preparing and Delayed are not additional approved normal state labels in the recorded mapping.

  1. Open an order belonging to your vendor and review its current saved status.
  2. Confirm an eligible Submitted order when acknowledging receipt and availability.
  3. Set Ready for Pickup only when the food is ready to collect.
  4. Set Closed Complete only after the customer actually collects the order.
  5. Refresh and check that the intended status was saved.

Use authorized actions only. If an action is unavailable, an order is canceled or the state changes unexpectedly, stop and ask the administrator to review it. Record delays through the agreed delay process rather than inventing a new state. Automatic reminders and disposal scheduling must not be assumed to be active.

An uncollected order is not Closed Complete. Ask the manager how to handle no-shows under the agreed policy.
