Vendor administrators maintain menu items for their own vendor. Vendor staff have read-only access in the prepared menu widget.

  1. Sign in with the assigned vendor administrator account and open menu maintenance.
  2. Choose an existing item to edit, or use Add when authorized.
  3. Review the name, description, price, category, availability and any ingredient or dietary details.
  4. Save and verify the saved values. Check the employee menu using an authorized test account.
  5. If a picture already exists, confirm it displays. The prepared vendor widget displays existing images; it does not supply image upload.

Keep allergen and nutrition information accurate and current. Check it against actual recipes, ingredient substitutions and supplier information. Missing details must not be described as allergen-free. Availability changes can affect food already in an employee's cart; checkout rechecks current availability and prices.

Do not edit another vendor's items. If authorized Add/Edit controls are missing or saving fails, ask the administrator to check role, group and field permissions.
