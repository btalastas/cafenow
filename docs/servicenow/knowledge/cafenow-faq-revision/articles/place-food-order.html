1. Browse a vendor menu and add available foods and quantities to your cart.
  2. Open the cart and review the foods, quantities, prices and total.
  3. Select an available pickup window for that vendor.
  4. Read and accept the terms. Ordering policy closes ordering 20 minutes before the window starts; for an 11:30 AM window, order before 11:10 AM.
  5. Select Place Order once and wait for the result.
  6. After success, note the order number and open My Orders to check the order and its items.

One checkout creates one CafeNow Order containing its Order Lines. The current journey does not require separate Service Catalog requests or RITMs.

The pilot does not collect payment. If checkout times out or the result is uncertain, check My Orders before trying again and ask support to review any unclear result. Repeated submissions can create duplicate orders.
